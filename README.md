# Smile Clock ☺

A cheerful, responsive analog clock that makes the present moment a little brighter. It follows your device's local time and includes a live digital display, date, timezone abbreviation, optional seconds hand, and an optional gentle tick sound.

## Run it

Open `index.html` in a modern browser. There is no build step, framework, dependency install, account, or server required. The Manrope and DM Mono typefaces load from Google Fonts; system font fallbacks are included.

## Features

- Live analog clock with hour, minute, and seconds hands
- Local digital time, date, and timezone abbreviation
- Toggle the seconds hand on and off
- Optional synthesized tick sound (off by default)
- Responsive layout, keyboard focus styles, and reduced-motion support
- No tracking, cookies, or external API calls
